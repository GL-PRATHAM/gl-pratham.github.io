# Portfolio gallery assets

Upload the contents of the supplied `GL-Pratham-Portfolio-Media-Pack.zip` into this folder, preserving the paths:

- `certificates/certificate-01.jpg` through `certificate-27.jpg`
- `event-photos/<photo-name>.jpg`

The homepage already contains the gallery markup and reads these exact paths. Until the ZIP contents are uploaded, image tiles will show as unavailable.

The certificate archive contains one image per PDF page. The event-photo folder contains the 16 supplied original photographs, converted to optimised JPEGs without cropping or compositing.

The LinkedIn section contains 18 unique direct post links. Titles and previews are intentionally generic until the original post content can be verified.
