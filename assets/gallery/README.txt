GL PRATHAM PORTFOLIO GALLERY

This folder contains:
- certificates/: 27 individual JPG images, one for each page of the certificate PDF.
- event-photos/: 16 original event/project photographs, converted to optimised JPEGs.
- media-manifest.json: file inventory for the galleries.
- linkedin-posts.json: 18 unique LinkedIn post URLs.

The homepage references the certificate and event-photo images using these relative paths.
LinkedIn post titles and previews remain generic until post contents are verified from screenshots or accessible public posts.
